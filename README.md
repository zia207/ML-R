A free, open-source tutorial that teaches every major machine learning algorithm by **building it from scratch in base R** — no `caret`, no `tidymodels`, no `keras`, no `torch`, no black boxes.

Read it online: **[https://zia207.github.io/ML-R](https://zia207.github.io/ML-R)**

## Philosophy

> The best way to understand an algorithm is to implement it from scratch.

Every chapter derives the idea, writes the math, then implements the algorithm with vectors, matrices, and explicit loops. You can read every line, change it, and see what happens.

Each chapter follows the same path:

1. **Intuition** — plain-English motivation
2. **Theory** — mathematical formulation with notation explained
3. **Algorithm** — step-by-step pseudocode
4. **From-scratch R** — complete, runnable implementation
5. **Exercises** — practice problems

## Who it is for

- R users who want to understand ML from first principles
- Students looking for a practical companion to an intro ML course
- Engineers who use ML packages and want to know what happens under the hood
- Anyone curious about the mathematics behind modern AI systems

**You need:** basic R (variables, loops, functions, vectors, data frames) and high-school algebra. No prior ML experience.

Recommended: [R 4.2+](https://cran.r-project.org/). Optional: `ggplot2` for plots. Algorithms themselves use only base R.

## Render locally

Requires [Quarto](https://quarto.org) and [R 4.2+](https://cran.r-project.org/).

```bash
quarto render
```

To preview:

```bash
quarto preview
```

Clone the repo and open `docs/index.html` (or the published site) to read the rendered chapters. The `.qmd` notebooks in `Notebook/` are the source of truth and should always be kept in the repository.
